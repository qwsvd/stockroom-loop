# 不看实现，亲手做三个实验

在本目录复制 starter.py 为 my_agent.py。修改自己的副本，运行 `python check.py 1`、`python check.py 2`、`python check.py 3`。起始文件有意留空。练习只用 Python，没有模型费用。

| 练习 | 目标与原理 | 最小例子 | 自己要写什么 | 测试与达标条件 | 常见错误 |
|---|---|---|---|---|---|
| 1. 安全动作 | 请求是数据，扣减前要检查数量 | 可用 2 件，取 1 件后剩 1 件 | 实现 take，返回新库存和成功标志。仅接受正整数 | check.py 1；成功、数量不足、布尔值和负数全部正确 | Python 的 True 也是 int 的子类；先扣再检查可能损坏状态 |
| 2. 带反馈的循环 | 每次决定都要看到最新结果，最多运行 budget 步 | 策略先 inspect，再按观察行动 | 实现 loop，调用 policy(history)、apply(action)，保存二元组列表，收到 terminal 后结束 | check.py 2；两步任务能结束，永远查看的策略也会按预算停止 | 忘记更新历史，或相信动作名称而没有看结果 |
| 3. 独立裁判 | 判断终态要有外部证据 | A 比 B 优先，初始各 2，订单 2，正确预留是 (2,0) | 实现 verify，核对两个批次的非负整数、逐批守恒、总量和优先顺序 | check.py 3；正确结果通过，错序、凭空多货和未完成均失败 | 只核对总数，忽略逐批库存 |

最后自行增加一个会失败的测试：模拟刚检查完 A 就被其他订单取走，再说明你如何修复。提交自己的实现、首次失败输出和修复说明。这个练习器检查的是几个例子，你还需要能解释程序为何在新输入上工作。
